# Contract: the text a prompt gains

A new section of `skills/study-pack/prompts.md`, found by its exact heading, «Standing rules — added to a prompt». Not measured.

```text
Reglas fijas de la familia para este alumno y esta asignatura: aplícalas en todo el resultado sin citarlas ni mencionarlas. Donde contradigan lo anterior mandan ellas, y las de la asignatura sobre las del alumno, salvo en qué entra en el examen y en seguir sus puntos, en las correcciones ya comprobadas, en seguir los esquemas de los apuntes, que mandan en la estructura y en las palabras, en comprobar cada número, en decir de qué fuente sale cada dato, en usar solo los problemas que se pide usar, en no culpar ni nombrar a nadie y en las frases y títulos que se piden entre comillas. {rules}
```

`{rules}` is `Del alumno: <text>` and `De la asignatura: <text>`, separated by a space, each only when that level has text, and within
a level `both` before the sheet's kind, separated by a space.

## How it is added

- After the prompt is filled and right-stripped, with one space before it. A prompt with nothing to add stays exactly as it was.
- `{rules}` is filled once. A rule's braces are never read as placeholders.
- A missing heading is `invalid_prompt`, as with the other texts, and `exam build` reads the section on every run, with or without
  rules, so a renamed heading never goes unnoticed.
- The limit counts `{rules}`, not the fixed sentences around it.

## Which prompt takes which

| Prompt | Added |
|---|---|
| Theory sheet, with and without an announcement | `both`, `theory` |
| Problems sheet, with and without an announcement | `both`, `problems` |
| Start notes | nothing |
| Study guide regenerated by `exam build` | nothing: a built-in format with no prompt |
| Skill: practice sheet, quiz, parent guide | `both`, `problems` |
| Skill: summary | `both`, `theory` |
| Skill: flashcards, glossary, tutor chat | `both` |
| Skill: video focus | what fits, the agent's judgement, reported |
| Skill: guide 0 | nothing: its prompt copies a block word for word, so the rules shape the `{plan}` the agent writes |
| Skill: the built-in study guide | nothing: no prompt |
